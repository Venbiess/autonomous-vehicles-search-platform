# Deployment Docs

This directory contains deployment resources for AVSP (Kubernetes and Docker Swarm).

## Start Here

- k3s workflow and local image import: [k3s/README.md](k3s/README.md)
- Helm chart usage and values: [helm/avsp/README.md](helm/avsp/README.md)
- Docker Swarm stack: [swarm/README.md](swarm/README.md)

## Directory Layout

- `k3s/`: helper script for local k3s deployment flow
- `helm/avsp/`: AVSP Helm chart (templates, values, chart metadata)
- `swarm/`: Docker Swarm stack file and deploy helper
